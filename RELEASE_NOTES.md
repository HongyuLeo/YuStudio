## 中文

Nocturne Studio 正式更名为 **YuStudio 1.3.0**。

- 同一个软件内切换 **中文 / English**，并记住语言选择。
- 编辑界面、性能参数、导出进度、错误提示与桌面项目对话框支持双语。
- 新程序名称、窗口标题与图标；继续使用兼容的旧项目和素材目录。
- 双语介绍页、中文 / 英文 README。
- 保留 v1.2.5 的原分辨率、帧率、粒子效果、NVENC、无损背景缓存与并发测速功能。

下载 **YuStudio-Windows-x64.zip**，完整解压后打开 **YuStudio.exe**。右上角选择语言。首次导出需要联网准备 Chromium。

## English

Nocturne Studio is now **YuStudio 1.3.0**.

- Switch between **中文 / English** inside one app, with a remembered preference.
- Bilingual editor, performance controls, export progress, errors and desktop project dialogs.
- New executable name, window title and icon, with compatible project files and legacy media profile reuse.
- Bilingual introduction website and separate Chinese / English READMEs.
- Preserves v1.2.5 resolution, FPS, effects, NVENC, lossless backgrounds and measured concurrency.

Download **YuStudio-Windows-x64.zip**, extract all files and open **YuStudio.exe**. Choose a language in the top-right corner. The first export needs an internet connection to prepare Chromium.

`YuStudio-Source.zip` is the source archive. `SHA256SUMS.txt` contains checksums for both ZIP files. The desktop package is unsigned.
